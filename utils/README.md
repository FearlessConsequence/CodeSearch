# CodeSearch

Консольная утилита для умного поиска по исходному коду с генерацией регулярных выражений. 
Проект написан на C++17.

## Основные возможности

Программа предлагает 6 режимов поиска:
1. **Структура** — поиск пустых блоков (`if { }`, `while { }`) и цепочек (X, потом Y, потом Z).
2. **Комбинирование** — поиск "X но не Y" (по позиции или по строке) и "X или Y или Z".
3. **Количество** — поиск чисел с N цифрами, строк длиной N символов и функций с N аргументами.
4. **Формат** — автоматический поиск Email, URL, IP-адресов, GUID и дат.
5. **Комментарии** — поиск слов в комментариях (в начале строки, в конце или везде).
6. **Слово с границами** — поиск конкретного слова с учетом границ (`\b`).

Дополнительно:
- **История и Избранное**: сохранение запросов в JSON-файлы.
- **Сохранение в файл**: возможность выгрузить найденные результаты в текстовый файл.
- **Гибкие настройки при поиске**: можно указать папку поиска, расширения файлов, исключения и максимальный размер файла.

## Быстрый старт

1. Запустите программу.
2. Выберите тип поиска (от 1 до 6) или зайдите в настройки (0).
3. Введите нужные параметры (например, слово для поиска).
4. Нажмите `3` (Начать поиск), настройте директорию и расширения файлов.
5. Наслаждайтесь результатами с подсветкой! Их можно скопировать в буфер (пункт `2`) или сохранить в файл (пункт `9`).

## Сборка

Для сборки требуется компилятор с поддержкой **C++17** (например, GCC/MinGW на Windows или Clang на macOS).

**Зависимости:**
Проект использует библиотеку `nlohmann/json` (она уже лежит в папке `include/`).

**Вариант 1: Сборка через консоль (g++)**
```bash
g++ -std=c++17 -O2 -o codesearch.exe main.cpp RegexBuilder.cpp FileSearcher.cpp Prompt.cpp
